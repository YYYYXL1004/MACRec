# Rebuttal baseline re-implementations: UNGER & MSCGRec

Faithful (pragmatic) re-implementations of two non-open-source baselines, in the
**unified CAGRec config** (same SASRec-collab / LLaMA-text / CLIP-image embeddings,
same T5-base backbone, same splits & metrics). Non-invasive: no changes to the
existing CAGRec training/eval pipeline.

## Files
| File | Role |
|---|---|
| `analysis/repro/residual_kmeans.py` | Hierarchical residual k-means (UNGER Alg.1); shared code generator |
| `analysis/repro/unger_stage1.py` | UNGER Stage-I: AdaLN modality adaption + CKA InfoNCE → integrated emb → unified code |
| `scripts/repro/run_unger.sh` | UNGER Stage-II: single-branch `seqrec` T5 train + eval |
| `data_mscgrec.py` | MSCGRec dataset: multimodal history, collaborative-code target |
| `finetune_mscgrec.py` / `test_mscgrec.py` | MSCGRec train / eval entry points |
| `scripts/repro/run_mscgrec.sh` | MSCGRec: gen 3-modality codes + train + eval |
| `scripts/repro/run_all_repro.sh` | One-shot: both methods for one dataset |

## Prerequisites on the run machine
Only the **base embeddings** are needed (already present from the prior transfer):
`data/{DS}/{DS}.emb-collab-256.npy`, `.emb-llama-td.npy`, `.emb-ViT-L-14.npy`,
plus `{DS}.inter.json` and the `.train/.valid/.test.inter` splits.
All discrete codes are regenerated by the scripts. `pip install scikit-learn` (and
`ipdb` is now optional — guarded import).

## Run (DS ∈ {Instruments, Arts, Games})
```bash
# both methods, one dataset, one GPU:
bash scripts/repro/run_all_repro.sh Instruments 0 29531

# 3 datasets in parallel on 3 GPUs:
bash scripts/repro/run_all_repro.sh Instruments 0 29531 &
bash scripts/repro/run_all_repro.sh Arts        1 29532 &
bash scripts/repro/run_all_repro.sh Games       2 29533 &
```

## Pragmatic approximations (state in the rebuttal footnote)
- **UNGER**: DIN → SASRec collab emb (unified config); Stage-I trains the AdaLN adapter
  with the CKA alignment loss only (next-item task subsumed by pretrained SASRec);
  IKD distillation omitted.
- **MSCGRec**: DINO self-supervised image quantization → standard residual RQ on CLIP
  features; constrained sequence learning applied at **inference** (collab-code trie)
  rather than in the training softmax; dual relative-position embeddings, empty-leaf
  redistribution and training-time modality masking omitted.
- Both report HR@10 honestly (a retrieval baseline may top raw recall on Arts/Games;
  see rebuttal §1.4 ranking-vs-recall framing).
